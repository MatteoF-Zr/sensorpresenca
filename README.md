Como instalar:
Pegue a pasta zip deste arquivo, abra com o Visual Code Studio (se necessário, instalar as extensões).
Inicializar o "SensorPresencaApplication" e conferir se o http://localhost:8080/index.html está funcionando corretamente.

abrir o CMD e digitar: 
winget install Cloudflare.cloudflared
e depois:
cloudflared tunnel --url http://localhost:8080/index.html

e agora está rodando corretamente :)
